# Changelog

## 0.1.1 — 2026-10-15

- Add a bounded repository policy check with value-free diagnostics.
- Build reproducible committed-source archives with SHA-256 manifests.
- Gate tag-based GitHub Releases with cross-platform tests and isolated publishing.
- Pin workflow actions and group monthly dependency update proposals.

## 0.1.0 — 2026-10-15

- Validated JSON task graphs with prerequisite selection and cycle detection.
- Bounded parallel execution, per-task deadlines and cancellation.
- Dependency failure propagation while independent tasks continue.
- Shell-free argument arrays and a portable `$node` executable token.
- Versioned reports and optional bounded child-output forwarding.
- Working demos, an Env Contract Check integration guide and self-hosted CI
  across Ubuntu/Windows and Node.js 22/24.
